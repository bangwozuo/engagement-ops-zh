# 高频问题转选题流程（faq-to-topic-flow）

> 触发：事件（每日评论聚合流程 daily-comment-aggregate-flow 跑完后自动衔接）
> 产出：选题库新增条目清单（Excel，全部「待人工确认」）
> 价值：评论区选题免费且精准——每条高优选题都自带"为什么拍它"的需求数据，
> 直接缓解第一痛点（选题枯竭）

# 流程目标

把提问类评论变成**可开拍的选题条目**：聚类 → 排榜 → 查重 → 定优先级，
全程数据可追溯（每条选题能回答"几个人问了、哪一周问的"），不让评论区里的
真实需求烂在信息流里。

# 步骤明细（每步含输入/处理/输出/失败处理）

## 步骤 1：提问聚类与高频问题榜

| 项 | 内容 |
|---|---|
| 技能 | `faq-cluster`（scripts/faq_cluster.py） |
| 输入 | 提问类评论流（上游四分类筛出的提问子集，或直接粘贴的问题列表） |
| 处理 | 归一化 → 相似度（bigram Jaccard / 编辑距离比取最大）≥ 0.60 贪心聚类 → 按频次降序 → Top 10 进 FAQ 库 |
| 输出 | out/faq_cluster.json + out/高频问题聚类.xlsx + out/faq_top10.png |
| 失败处理 | 退出码 ≠0 → 中止打印 stderr；提问内容为空/无实义词 → 汇总标注「输入无效」，不产出虚假榜单；**Top10 覆盖率 < 60% → 正常继续但标注「问题过散」**，供下一步决策参考 |

## 步骤 2：查重与选题条目生成

| 项 | 内容 |
|---|---|
| 技能 | `topic-knowledge-base`（条目化规则内置于 run_flow.py，口径与 prompt 一致） |
| 输入 | 步骤 1 的 faq_cluster.json + 既有选题库清单（existing_topics） |
| 处理 | 逐 Top10 簇生成条目：优先级（频次 ≥5 高 / 3-4 中 / <3 低）→ 查重（与既有选题编辑距离比 ≥ 0.60 判重复）→ 选题建议（按簇关键词映射可开拍角度：渠道类→「WHERE 买指南」、价各类→「值不值横评」、肤质类→「按肤质怎么选」…） |
| 输出 | out/选题库新增条目.xlsx（全部「待人工确认」）+ out/topic_flow_result.json |
| 失败处理 | 上游产物缺失 → 中止提示重跑；全部条目重复 → 正常退出并标注「无新增，跳过入库」；既有库为空 → 全部按新增处理并提示「新库已建立」 |

## 步骤 3：人工确认与入库（流程终点）

| 项 | 内容 |
|---|---|
| 处理 | 主理人每周一审核候选：勾选入库 / 合并同类 / 淘汰重复；入库后状态改「已入库」，拍完改「已拍」并回填链接 |
| 失败处理 | 语义近似但用词不同的选题（脚本查不出）由模型按 topic-knowledge-base 的 prompt 复核；低优先级占比 > 50% 时建议先置顶 Q&A 沉淀频次，不逐条开拍 |

# 量化规则（判定不看感觉）

- 合并阈值：相似度 ≥ 0.60 归同簇（宁可漏合不可错合——答案错配比多写一条 FAQ 更糟）
- 优先级：频次 ≥5 高 / 3-4 中 / <3 低；**频次并列时簇内变体多者靠前**
- 覆盖率自检：Top10 覆盖率 < 60% 判「分类有误/问题过散」
- 库健康：重复率 > 20% 或低优先级占比 > 50% 触发清理（库死亡的第一信号是重复堆积）
- 高优选题产出节奏：连续 2 周无高优选题 → 说明内容信息密度已覆盖当前疑问，
  应主动开新话题制造新问题，而不是等

# 失败模式（编排层特有）

- **上游混入吐槽**：提问子集必须先经情感分类（daily-comment-aggregate-flow 的产出），
  否则「有没有不这么水的版本」会变成"选题"
- **历史查重缺失**：本流程只对「既有库」查重，跨周期的重复问题靠每月库体检兜底——
  「在哪买」寒假问过、暑假再问，若库里有「已拍」的同题条目应提示「做续集/更新版」而非新条目
- **频次通胀**：单条爆款视频会制造临时高频问题（某次提到某产品），跨周频次才可信——
  建议条目标注统计周期，单周频次仅供参考
- **人工确认积压**：候选条目连续 2 周无人确认 → 流程在汇总里标红提醒，超过 4 周的
  候选自动降级（热度已过）

# 输出格式（选题库新增条目清单）

```markdown
## 本期新增候选
| 选题ID | 来源问题簇 | 频次 | 优先级 | 选题建议 | 查重结果 | 状态 |
|---|---|---|---|---|---|---|

## 汇总
| 项 | 内容 |
|---|---|
| 候选选题数 / 查重后新增 / 重复 | n / n / n |
| 高优先级选题 | n（频次 ≥5） |
| 入库规则 | 全部待人工确认；人工勾选后才写入正式选题库 |
```

# 编排规则

- DAG 节点 = 本仓真实技能 slug：`faq-cluster` → `topic-knowledge-base`
- 步骤间经 JSON 文件衔接（out/faq_cluster.json），不在提示词里传大段原文
- 模型介入点：语义二次合并（聚类盲区）、选题建议润色、库体检复核
- 写入库的唯一路径是人工确认后的本地文件更新；不自动写任何平台

# 合规

- 清单标注「AI 生成内容」，仅内部使用
- 选题涉及的品类宣称（功效/价格）在拍摄脚本阶段另行过合规审查
- 条目不存用户昵称（存簇 ID 追溯）；评论数据仅用于频次统计
