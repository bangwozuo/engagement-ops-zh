# 铁粉识别与互动名单流程（superfan-identify-flow）

> 触发：定时，每周一 10:00（汇总上周互动数据后运行）
> 产出：铁粉维护名单 + 私域移交确认清单（Excel，全部「待人工确认」）
> 价值：铁粉名单直接输送给私域转化环节，为私域增收供弹药；
> 参考「1% 超级用户贡献 90% 互动」的经验分布，把维护精力投向贡献大头

# 流程目标

把上周互动记录换算成**可执行的维护名单**：谁该感谢、谁该安抚、谁只记录不互动，
每个动作都带人工确认点——识别出铁粉只是开始，名单能不能安全合规地变成互动
才是价值所在。

# 步骤明细（每步含输入/处理/输出/失败处理）

## 步骤 1：互动统计与九宫格分层

| 项 | 内容 |
|---|---|
| 技能 | `fan-segmentation-tag`（scripts/segment.py） |
| 输入 | 上周（建议累计 ≥2 周）互动记录：user/type（comment/like/dm/share/collect）/sentiment（来自评论情感分类） |
| 处理 | 周均互动 = 总互动 ÷ 周数 → 频次档（高 ≥5 / 中 2-4 / 低 <2）× 情感档（正 ≥60% / 中性 40-60% / 负 <40%）落九宫格；铁粉评分 = 频次 50% + 正情感率 30% + 私信深度 20% |
| 输出 | out/segment.json + out/粉丝分层清单.xlsx + out/粉丝分层结构.png |
| 失败处理 | 退出码 ≠0 → 中止打印 stderr；互动记录为空 → 「本周无互动」名单正常退出；统计周期 <2 周 → 汇总输出噪音警告；记录缺 sentiment 字段 → 该用户按中性处理并标注 |

## 步骤 2：维护动作与移交清单生成（内置规则）

| 项 | 内容 |
|---|---|
| 输入 | 步骤 1 的 segment.json |
| 处理 | 铁粉候选 → 维护动作（感谢回访 / 专属福利 / 进群邀请；评分 ≥70 加邀内容共创）；需安抚 → 2 小时 SLA 工单移交 reply-script-advice-flow；潜在黑粉观察 → 只记录不互动。**全部动作标「待人工确认」** |
| 输出 | out/铁粉维护名单.xlsx（名单 + 私域移交确认清单 + 汇总）+ out/superfan_flow_result.json |
| 失败处理 | 上游产物缺失 → 中止；铁粉候选为 0 → 正常退出并标注「检查阈值（≥5 次/周 且 正情感率 ≥60%）或延长统计周期」；疑似刷量号（高互动全中性无文本）→ 保留明细标「待模型复核」，不进名单 |

## 步骤 3：人工确认与移交（流程终点）

| 项 | 内容 |
|---|---|
| 处理 | 主理人逐项确认：① 名单移交私域（勾选后才建联）② 福利预算与规则报备 ③ 私信话术过 reply-script-generate 生成并确认后发送 |
| 失败处理 | 确认积压 > 1 周 → 名单随下周重跑自动刷新（旧名单作废）；确认后粉丝状态反转（如高频负面）→ 名单备注作废理由，不追溯已执行动作 |

# 量化规则（判定不看感觉）

- 九宫格阈值：高频 ≥5 次/周；正情感率 ≥60% 正 / 40-60% 中 / <40% 负
- 铁粉评分 0-100：频次 50% + 正情感率 30% + 私信深度 20%；**≥70 才能进「内容共创/试用邀约」层**
- 集中度基准：TOP 10% 粉丝互动占比 ≥60% 健康；<30% 说明无核心粉丝群，
  应先做互动钩子再跑本流程（否则名单全是弱互动用户）
- 维护容量约束：单周铁粉维护动作 ≤ 名单人数 × 2 项（感谢+福利），
  超过说明阈值该收紧（提高高频线），维护要可持续而不是一次性撒网

# 失败模式（编排层特有）

- **情感标注缺失**：segment 输入的 sentiment 字段来自评论情感分类，
  上游没跑分类就互动字段全空 → 全员按中性处理，铁粉识别失效——
  流程在汇总里强制检查 sentiment 覆盖率，<50% 标红
- **刷量号混入**：互赞群 14 次互动全是点赞，机器统计会落「高潜互动」——
  名单必须过模型复核（批量命名特征/无文本/互动时间聚集）后剔除
- **私信任性踩限**：平台对陌生人私信限流，铁粉触达优先评论区翻牌；
  进群邀请人数 >200 时分批，避免触发风控
- **名单外流**：名单含粉丝昵称与互动画像，属于敏感运营数据——
  文件不进群、不外发，交接只说人数与结论

# 输出格式（铁粉维护名单）

```markdown
## 铁粉维护名单
| 名单序号 | 用户 | 周均互动 | 正情感率 | 铁粉评分 | 建议动作 | 状态 |
|---|---|---|---|---|---|---|

## 私域移交确认清单
| 移交项 | 内容 | 确认点 |
|---|---|---|
| 铁粉名单（私域转化环节接手） | 共 n 人 | 主理人勾选同意后才移交联系方式/建联 |
| 需安抚名单（回复工单环节接手） | 共 n 人 | 2 小时 SLA 内回复 |
| 潜在黑粉观察名单 | 共 n 人 | 只记录不互动 |

## 汇总
| 项 | 内容 |
|---|---|
| 铁粉候选 / 需安抚 / 黑粉观察 | n / n / n |
| TOP 10% 互动占比 | x%（基准 ≥60% 健康） |
| 人工确认点 | 名单移交 / 福利发放 / 私信触达 全部需人工确认 |
```

# 编排规则

- DAG 节点 = 本仓真实技能 slug：`fan-segmentation-tag`（唯一上游统计技能）
- 步骤间经 JSON 文件衔接（out/segment.json）
- 模型介入点：刷量号复核、感谢/邀约话术生成（走 reply-script-generate）
- 触达动作（私信/进群/福利）零自动化，全部人工执行

# 合规

- 名单标注「AI 生成内容」，仅限本账号运营与私域转化环节内部使用，**不外发、不进群**
- 名单移交私域前必须人工确认；未经确认不得私信营销或批量拉群
- 粉丝昵称与互动画像属用户数据，仅用于本账号运营；条目不存联系方式，
  联系方式的移交由人工在确认后进行
