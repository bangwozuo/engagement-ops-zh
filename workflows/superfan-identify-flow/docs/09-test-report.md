## 三、边界与已知限制

| 限制 | 说明 |
|---|---|
| sentiment 依赖上游 | 情感标注缺失会让全员落中性档，流程以覆盖率 <50% 标红兜底 |
| 小样本噪音 | 粉丝数 <50 时 TOP 10% 集中度仅供参考，阈值判定以名单质量为主 |
| 刷量号识别 | 统计特征由模型复核，机器不做唯一裁决 |
| 名单时效 | 粉丝状态每周变化，确认积压 >1 周的名单作废重跑 |
