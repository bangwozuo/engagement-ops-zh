# 高频问题聚类

把提问类评论里的重复问法合并成问题簇，按频次排出**高频问题榜**，Top 10 配标准答案
要点进 FAQ 库——从「逐条回答重复问题」变成「一条置顶 FAQ 回答一百个人」。

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_media_03_sk02` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 评论运营官 |
| 能力族 | 归纳聚类型 · FAQ 运营 |
| 复杂度 | `M` |
| 阶段 | `P0` |
| 复用度 | 高（faq-to-topic-flow、topic-knowledge-base 上游） |
| 资产形态 | 纯提示词 + Python 脚本（无模型调用、无 API Key） |

## 能力描述

1. **相似度聚类**：字符 bigram Jaccard 与编辑距离比取最大值，≥ 0.60 归同簇
2. **高频问题榜**：按簇频次降序，频次并列时变体多者靠前（问法发散更值得写 FAQ）
3. **FAQ 库 Top 10**：每簇给标准问法 + 按关键词定口径的建议答案要点 + 回复口径限制
4. **覆盖率自检**：Top 10 覆盖率 < 60% 判「分类有误/问题过散」，提示人工复核
5. **产物**：Excel（FAQ 库 / 簇明细 / 汇总）、Top 10 频次柱状图、JSON

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `questions` | array | ✅ | 提问类评论列表（字符串或 `{text}` 对象）；先经情感分类剔除吐槽 |
| `account` | string | ⬜ | 账号名 |
| `period` | string | ⬜ | 统计周期，如 2026-09-23 ~ 2026-09-29 |

## 输出规格

- `summary`：原始提问数 / 独立问法数 / 聚类簇数 / Top10 覆盖率 / 判定
- `clusters`：全部问题簇（代表问题 / 变体数 / 频次 / 占比 / 是否进FAQ库）
- `faq`：FAQ 库 Top 10（标准问法 / 频次 / 建议答案要点 / 回复口径限制）
- 产物文件：`out/高频问题聚类.xlsx`、`out/faq_top10.png`、`out/faq_cluster.json`

## 使用步骤

### 方式一：纯提示词（最快）

1. 把 `prompt.txt` 全部内容粘贴为系统提示词
2. 提供提问类评论列表
3. 得到问题榜与 FAQ 建议；语义近似但用词不同的问法由模型二次合并

### 方式二：带脚本（精确聚类 + 产出 Excel）

```bash
python3 <SKILL_DIR>/scripts/faq_cluster.py --input input.json --outdir out
python3 <SKILL_DIR>/scripts/faq_cluster.py --demo
```

产物：

| 文件 | 内容 |
|---|---|
| `out/高频问题聚类.xlsx` | FAQ库Top10 / 问题簇明细（Top10 标记）/ 汇总 |
| `out/faq_top10.png` | Top 10 频次柱状图 |
| `out/faq_cluster.json` | 机器可读结果，供工作流读取 |

**分工**：脚本做归一化、相似度、聚类与覆盖率（不漏、不猜）；模型做语义二次合并与
答案口径把关。数值以脚本输出为准，不要自己算。

## 边界（不做的事）

- ❌ 不把吐槽当 FAQ（「有没有不这么水的版本」先过情感分类）
- ❌ 不合并答案不同的相似问法（「多少钱」≠「为什么这么贵」）
- ❌ FAQ 答案不引导站外交易、不承诺效果；肤质问题带「个体差异/建议就医」口径
- ❌ 提问内容缺失列清单让用户补，不猜
- ❌ 不编造频次——榜单数字只有脚本实跑结果

## 调用示例

**输入**（`examples/input.json`，节选）：

```json
{
  "account": "@小鹿的好物日记",
  "period": "2026-09-23 ~ 2026-09-29",
  "questions": ["在哪买", "在哪买啊", "姐妹在哪买", "求链接", "求个链接", "求链接！", "多少钱"]
```

| Q02 | 在哪买 | 3 | 3 | ✅ Top10 |
| Q03 | 多少钱 | 3 | 3 | ✅ Top10 |
| Q04 | 油皮能用吗 | 2 | 2 | ✅ Top10 |
| … | … | … | … | … |

汇总：13 簇，Top10 覆盖率 87%，判定「正常」。
