# 粉丝分层打标

把一段周期内的互动记录换算成每个粉丝的「互动频次 × 情感倾向」二维坐标，落到九宫格，
输出**铁粉候选名单、需安抚名单与维护动作建议**。

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_media_03_sk04` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 评论运营官 |
| 能力族 | 打分分层型 · 粉丝运营 |
| 复杂度 | `S` |
| 阶段 | `P1` |
| 复用度 | 中（superfan-identify-flow、私域转化环节引用） |
| 资产形态 | 纯提示词 + Python 脚本（无模型调用、无 API Key） |

## 能力描述

1. **二维矩阵九宫格**：频次（高频 ≥5 次/周、中频 2-4、低频 <2）× 情感（正 ≥60%、中性 40-60%、负 <40%）
2. **铁粉评分（0-100）**：频次×50% + 正情感率×30% + 私信深度×20%，≥70 可邀共创/试用
3. **集中度对照**：TOP 10% 粉丝互动占比 vs「1% 超级用户贡献 90% 互动」的行业基准
4. **产物**：Excel 分层清单（需安抚标红 + 铁粉名单 sheet）、分层结构柱状图、JSON

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `interactions` | array | ✅ | 互动记录，元素含 `user`/`type`（comment/like/dm/share/collect）/`sentiment`（pos/neg/neutral/空） |
| `weeks` | number | ✅ | 统计周期周数（≥2，太短高频噪音大） |
| `account` | string | ⬜ | 账号名 |

`sentiment` 来源于 comment-sentiment-analyze 的分类结果（正面=赞美、负面=吐槽/黑粉）。

## 输出规格

- `summary`：粉丝总数 / 铁粉候选数 / 需安抚数 / 黑粉观察数 / TOP 10% 互动占比
- `items`：逐人分层结果（周均互动 / 频次档 / 正情感率 / 分层标签 / 铁粉评分 / 建议动作）
- 产物文件：`out/粉丝分层清单.xlsx`（分层明细 + 铁粉名单 + 集中度基准）、
  `out/粉丝分层结构.png`、`out/segment.json`

## 使用步骤

### 方式一：纯提示词（最快）

1. 把 `prompt.txt` 全部内容粘贴为系统提示词
2. 提供互动记录与统计周期
3. 得到九宫格分层与维护动作建议；刷量号/互赞群由模型复核剔除

### 方式二：带脚本（精确统计 + 产出 Excel）

```bash
python3 <SKILL_DIR>/scripts/segment.py --input input.json --outdir out
python3 <SKILL_DIR>/scripts/segment.py --demo
```

产物：

| 文件 | 内容 |
|---|---|
| `out/粉丝分层清单.xlsx` | 分层明细（需安抚标红）/ 铁粉名单 / 集中度基准 |
| `out/粉丝分层结构.png` | 各层人数柱状图 |
| `out/segment.json` | 机器可读结果，供工作流读取 |

**分工**：脚本做频次/情感率统计与矩阵落格（不漏、不猜）；模型复核刷量号、互赞群、
竞品卧底三类不许进名单的账号。数值以脚本输出为准，不要自己算。

## 边界（不做的事）

- ❌ 不公开粉丝名单或分层结果——公开会引发"被分层"的粉丝对立
- ❌ 不给疑似刷量号/互赞群发福利
- ❌ 私信营销与批量拉群未经人工确认不执行
- ❌ 记录缺失的用户标「数据不足，暂不分层」，不估算
- ❌ 高频负面用户不进铁粉名单——互动≠价值，需安抚是警报不是荣誉

## 调用示例

**输入**（`examples/input.json`，节选）：

```json
{
  "account": "@小鹿的好物日记",
  "weeks": 2,
  "interactions": [
    {"user": "奶盖不加糖", "type": "comment", "sentiment": "pos"},
    {"user": "奶盖不加糖", "type": "dm", "sentiment": "neutral"},
    {"user": "打工人小王", "type": "comment", "sentiment": "neg"}
  ]
}
```

**输出**（脚本实跑，2 周数据 10 名粉丝）：

| 用户 | 周均互动 | 频次档 | 正情感率 | 分层标签 | 铁粉评分 |
|---|---|---|---|---|---|
| 奶盖不加糖 | 5.0 | 高频 | 100% | 铁粉候选 | 75.7 |
| 美妆课代表 | 5.0 | 高频 | 100% | 铁粉候选 | 65.7 |
| 打工人小王 | 5.0 | 高频 | 0% | 需安抚 | 35.7 |
| 今天也很困 | 0.5 | 低频 | 0% | 潜在黑粉观察 | 3.5 |

汇总：铁粉候选 3 / 需安抚 1 / 黑粉观察 1。
