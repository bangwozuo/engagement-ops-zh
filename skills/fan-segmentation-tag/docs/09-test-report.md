## 三、边界与已知限制

| 限制 | 说明 |
|---|---|
| 情感标注依赖上游 | sentiment 字段来自 comment-sentiment-analyze；上游误判会传导 |
| 周期 ≥2 周 | <2 周的高频判定噪音大，脚本在汇总中输出警告 |
| 刷量号识别靠模型 | 机器只看统计特征，昵称/行为模式的批量特征由模型按 prompt.txt 复核 |
| 点赞权重 | 点赞与评论同计数但私信深度单列 20% 权重，避免"伪高频" |
