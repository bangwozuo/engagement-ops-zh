# 人设语气库

把创作者的说话方式整理成**可执行的语气库档案**，再逐条检查回复草稿的一致性——
评论区是账号人设密度最高的地方，一条出戏的回复毁掉十条用心的视频。

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_media_03_sk06` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 评论运营官 |
| 能力族 | 规范约束型 · 人设管理 |
| 复杂度 | `S` |
| 阶段 | `P0` |
| 复用度 | 高（reply-script-generate、reply-script-advice-flow 的质检下游） |
| 资产形态 | 纯提示词 + Python 脚本（无模型调用、无 API Key） |

## 能力描述

1. **语气库档案**：人设/平台/受众/称呼/口头禅/句长上限/禁用词（带理由）
2. **一致性打分（0-100）**：称呼 40 + 口头禅 20 + 句长（≤20 字/句）20 + 零违禁 20，≥80 达标
3. **合规否决**：效果承诺 / 绝对化用语（《广告法》第九条）/ 站外导流 / 诱导互动，
   任一命中直接禁止发布
4. **批次达标率**：≥80% 人设稳定；连续两批 <60% 需回炉语气库
5. **产物**：Excel（档案 + 检查明细，不达标标红）、得分柱状图、JSON

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `voice` | object | ✅ | 语气库档案：`persona`/`platform`/`audience`/`称呼`/`口头禅`/`句长上限`/`禁用词`/`禁用词理由` |
| `drafts` | array | ✅ | 回复草稿列表，元素含 `id`/`comment_id`/`text` |

## 输出规格

- `summary`：档案摘要 + 草稿总数 / 达标数 / 达标率 / 合规否决数
- `items`：逐条检查明细（各分项得分 / 一致性得分 / 判定 / 检查明细）
- 产物文件：`out/语气一致性检查.xlsx`、`out/voice_scores.png`、`out/voice_check.json`

## 使用步骤

### 方式一：纯提示词（最快）

1. 把 `prompt.txt` 全部内容粘贴为系统提示词
2. 提供语气库档案与回复草稿
3. 得到逐条检查结果；语气自然度与梗的时效由模型判断

### 方式二：带脚本（精确检查 + 产出 Excel）

```bash
python3 <SKILL_DIR>/scripts/voice_check.py --input input.json --outdir out
python3 <SKILL_DIR>/scripts/voice_check.py --demo
```

产物：

| 文件 | 内容 |
|---|---|
| `out/语气一致性检查.xlsx` | 语气库档案 / 检查明细（不达标标红）/ 汇总 |
| `out/voice_scores.png` | 各草稿一致性得分柱状图（达标线 80） |
| `out/voice_check.json` | 机器可读结果，供工作流读取 |

**分工**：脚本做命中率/句长/违禁词的精确检查（不漏、不猜）；模型判断口头禅是否
塞得太硬、梗是否过时。数值以脚本输出为准，不要自己算。

## 边界（不做的事）

- ❌ 合规否决的草稿不给变通写法（"+薇"= 规避审核，属违规协助）
- ❌ 不公开语气库档案——被看穿人设是设计出来的就是塌房素材
- ❌ 不检查非本账号人设的草稿（多账号防串味，先确认账号）
- ❌ 档案字段缺失列清单让用户补，不用默认词表硬检
- ❌ 命中率不造假，谐音不算命中

## 调用示例

**输入**（`examples/input.json`，节选）：

```json
{
  "voice": {
    "称呼": ["宝子", "姐妹", "家人们"],
    "口头禅": ["码住", "冲鸭", "亲测", "说真的"],
    "句长上限": 20,
    "禁用词": ["绝绝子", "yyds", "亲～"]
  },
  "drafts": [
    {"id": "D1", "comment_id": "C001", "text": "宝子，黄二白建议选 12 号，亲测不假白，色号对比在置顶视频码住～"},
    {"id": "D4", "comment_id": "C003", "text": "亲～本产品 100% 正品保证，绝绝子好用，加微信还有专属优惠哦！"}
  ]
}
```

**输出**（脚本实跑，6 条草稿）：达标 4（67%），合规否决 1。
D1 得 100 分（称呼宝子 + 口头禅亲测/码住 + 句长 7.8 字 + 零违禁）；
D4 触发三重合规否决（100% 效果承诺、绝绝子禁用词、加微信站外导流）→ 禁止发布。
