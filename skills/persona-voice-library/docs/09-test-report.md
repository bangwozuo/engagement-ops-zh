### 质量核对

| 检查 | 结果 |
|---|---|
| 打分规则 | D3 = 40+0+20+20 = 80，与手工核算一致 ✅ |
| 合规否决一票制 | D4 命中效果承诺/禁用词/导流三类，判「禁止发布」✅ |
| 「第一时间」不误伤 | D5 含「第一时间告诉你」，词表用「第一(?!时间)」负向断言，未误报 ✅ |
| 口语断句 | 句长按逗号/句号断句取平均，D1（34 字长句）拆为 7.8 字均值 ✅ |

### 迭代记录（修复的问题）

1. 初版正则 `+v` 未转义导致崩溃 → 转义修复
2. 初版「第一」误伤「第一时间」→ 负向断言修复
3. 初版句长按句号断句，无句号的评论被记 34 字 → 加入逗号断句点

## 三、边界与已知限制

| 限制 | 说明 |
|---|---|
| 语气自然度 | 命中率 100% 仍可能像机器人，须由模型复核（允许 20% 自然变体） |
| 梗的时效 | 禁用词表外的过时梗脚本查不出，靠模型与月度词表校对 |
| 多账号 | 脚本不知道"当前是哪个号"，输入必须带对人设档案 |
| 归一化局限 | 谐音变体（"绝绝籽"）不检测——按 prompt.txt，也不提供此类变通写法 |
