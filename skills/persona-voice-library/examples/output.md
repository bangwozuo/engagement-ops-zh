## D4 的违禁明细（为何一票否决）

原文：「亲～本产品 100% 正品保证，绝绝子好用，加微信还有专属优惠哦！」

1. `100% 保证` → 效果承诺（回复不得承诺内容效果或商品效果）
2. `绝绝子` / `亲～` → 语气库禁用词（过时梗 + 电商客服腔）
3. `加微信` → 站外导流（平台规则：评论区不得引导站外交易/导流）

按 prompt.txt 约定，**不给"加V/＋薇"式变通写法**——那是规避审核，属违规协助。
合规改写方向：删掉导流与承诺，用语气库口径重写（人工确认后发布）。
