## 三、边界与已知限制

| 限制 | 说明 |
|---|---|
| 反讽/阴阳怪气 | 词表无法识别，须由模型按 prompt.txt 复核（如「可真是谢谢你哦」） |
| 老粉玩笑 | 熟 ID 的攻击性用语可能是调侃，需结合历史互动判断 |
| 词表非穷尽 | 新梗（如新兴黑话）需定期补词表；长尾由模型兜底 |
| 分类 ≠ 处理 | 输出仅为处理建议，隐藏/举报/回复需人工在平台后台执行 |
