# 评论情感分析

把一天涌进来的评论按「提问 / 赞美 / 吐槽 / 黑粉」四分类，给出情绪强度（1-5 分）与
处理时限（SLA），产出**按优先级排好的处理队列**——先救火，再闲聊。

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_media_03_sk01` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 评论运营官 |
| 能力族 | 检测判断型 · 情感分类 |
| 复杂度 | `M` |
| 阶段 | `P0` |
| 复用度 | 高（粉丝分层、回复话术、每日聚合流程共用） |
| 资产形态 | 纯提示词 + Python 脚本（无模型调用、无 API Key） |

## 能力描述

1. **四分类**：提问 / 赞美 / 吐槽 / 黑粉（+闲聊兜底），词表 + 表情权重双通道判定
2. **情绪强度打分（1-5）**：命中词权重 + 表情权重（😡🤬 计 2）+ 重复标点，封顶 5
3. **SLA 处理队列**：黑粉 30 分钟内 > 吐槽 2 小时内 > 提问 4 小时内 > 赞美点赞即可
4. **产物**：Excel 处理清单（黑粉标红）、四分类占比饼图、机器可读 JSON

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `comments` | array | ✅ | 评论列表，元素含 `id`/`user`/`text`/`likes`（点赞数可选，缺省按 0） |
| `account` | string | ⬜ | 账号名，写入汇总 |
| `platform` | string | ⬜ | 抖音 / 小红书 / B站 / 公众号 / 通用 |
| `date` | string | ⬜ | 统计日期，如 2026-09-29 |

## 输出规格

- `summary`：评论总数 / 四分类计数 / 黑粉占比 / 负类合计占比 / 需 2 小时内处理条数
- `items`：逐条分类结果（类别 / 强度 / 处理时限(SLA) / 建议动作 / 命中依据），按 SLA 排序
- 产物文件：`out/评论分类处理清单.xlsx`、`out/评论情感分布.png`、`out/sentiment.json`

## 使用步骤

### 方式一：纯提示词（最快）

1. 打开你的 AI 工具，把 `prompt.txt` **全部内容**粘贴为系统提示词
2. 提供评论列表（直接粘贴或给 JSON）
3. 得到四分类结果与处理队列；反讽/老粉玩笑等语境项由模型判断

### 方式二：带脚本（词表精确扫描 + 产出 Excel）

```bash
python3 <SKILL_DIR>/scripts/sentiment_scan.py --input input.json --outdir out
python3 <SKILL_DIR>/scripts/sentiment_scan.py --demo     # 无输入也能看效果
```

产物：

| 文件 | 内容 |
|---|---|
| `out/评论分类处理清单.xlsx` | 处理队列（黑粉标红）/ 汇总 |
| `out/评论情感分布.png` | 四分类占比饼图 |
| `out/sentiment.json` | 机器可读结果，供工作流读取 |

**分工**：脚本做词表精确匹配与 SLA 排序（不漏、不猜）；模型做反讽识别、黑粉与激烈
吐槽的边界复核。数值以脚本输出为准，不要自己算。

## 边界（不做的事）

- ❌ 不与黑粉对线，不输出反驳/拉踩/讽刺性回复
- ❌ 不建议删负面评论（违规除外）；删除差评会激化并截图反噬
- ❌ 不把老粉调侃判成黑粉（高频正情感历史互动者降级为吐槽）
- ❌ 不编造处理结果——分类输出 ≠ 已处理，动作需人工执行
- ❌ 评论内容缺失时列清单让用户补，不猜内容

## 调用示例

**输入**（`examples/input.json`，节选）：

```json
{
  "account": "@小鹿的好物日记",
  "platform": "抖音",
  "date": "2026-09-29",
  "comments": [
    {"id": "C001", "user": "奶盖不加糖", "text": "姐这个粉底液色号是多少呀？黄二白能用吗", "likes": 12},
    {"id": "C003", "user": "黑粉本粉", "text": "就是骗子！收钱恰烂饭，大家都别买，我去举报了😡", "likes": 1}
  ]
}
```

**输出**（脚本实跑，12 条评论）：

| 评论ID | 类别 | 强度 | 处理时限(SLA) | 命中依据 |
|---|---|---|---|---|
| C010 | 黑粉 | 5 | 30 分钟内 | 黑粉词:垃圾/搬运狗/人设崩塌 |
| C003 | 黑粉 | 5 | 30 分钟内 | 黑粉词:骗子/恰烂饭/都别买；强负表情:😡 |
| C009 | 吐槽 | 5 | 2 小时内 | 吐槽词:退步/不如以前/失望；强负表情:😭 |
| C005 | 吐槽 | 5 | 2 小时内 | 吐槽词:划水/广告太多；含问题需一并回复 |
| C001 | 提问 | 1 | 4 小时内 | 疑问句式(强) |
| C004 | 赞美 | 4 | 点赞即可 | 赞美词:绝了；正表情:❤️ |

汇总：黑粉 2 / 吐槽 3 / 提问 3 / 赞美 3 / 闲聊 1，需 2 小时内处理 5 条。
