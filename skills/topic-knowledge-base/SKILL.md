# 选题知识库

维护「评论区 → 选题库」入口：把问题簇转成结构化选题条目，查重、排优先级、记来源，
让创作者「下次不知道拍什么」时打开库就有答案——评论区的提问是最免费且最精准的
选题来源。

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_media_03_sk05` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 评论运营官 |
| 能力族 | 调度维护型 · 知识库 |
| 复杂度 | `S` |
| 阶段 | `P0` |
| 复用度 | 高（faq-to-topic-flow 末端、创作者选题决策的入口） |
| 资产形态 | SOP 提示词 + 只读连接器约定（无 API Key、不自动写平台） |

## 能力描述

1. **条目结构**：选题ID / 来源问题簇 / 提问频次 / 优先级 / 选题建议 / 查重结果 / 状态
2. **优先级规则**：频次 ≥5 高 / 3-4 中 / <3 低；频次即热度，不掺个人好恶
3. **查重**：与库内既有条目编辑距离比 ≥ 0.60 判重复，重复淘汰或合并
4. **库健康度**：重复率 >20% 或低优先级占比 >50% 触发清理；带时效选题必须标过期时间
5. **闭环**：「已拍」条目回填链接，季度统计选题采纳率与播放表现

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `faq_clusters` | array | ✅ | faq-cluster 输出的问题簇（代表问题/频次），或直接粘贴的问题列表 |
| `existing_topics` | array | ⬜ | 库内既有选题标题，用于查重；没有则新建库 |
| `account` / `period` | string | ⬜ | 账号与统计周期 |

## 输出规格

- `candidates`：本期新增候选条目（全部「待人工确认」）
- `health`：库健康度（总数 / 待确认 / 重复率 / 低优先级占比 / 触发的清理规则）
- `need_human`：勾选入库与建议淘汰清单（附依据）

## 使用步骤

### 方式一：直接使用（最快）

1. 把 `prompt.txt` 全部内容粘贴为系统提示词
2. 提供问题簇数据（faq-cluster 产物或粘贴的高频问题）+ 现有选题清单
3. 得到候选条目与库健康度报告，人工勾选后写入本地库

### 方式二：由工作流自动衔接

`faq-to-topic-flow` 的第 2 步即本技能：上游 faq-cluster 跑完后自动生成
`out/选题库新增条目.xlsx`，人工确认后并入正式库。

### 连接器与降级

| 数据源 | 方式 | 降级路径 |
|---|---|---|
| 评论区导出 | 平台后台导出 CSV/Excel（只读） | 不给导出就手动粘贴高频评论 |
| faq-cluster | 上游 JSON | 无脚本环境把问题列表直接给模型 |
| 历史选题库 | 本地 Excel/CSV | 没有库就本次新建 |

## 边界（不做的事）

- ❌ 不编造提问频次——条目频次必须可追溯到 faq-cluster 实跑结果
- ❌ 不混入创作者自嗨选题（本库只收来自评论区的提问型选题）
- ❌ 选题建议不写「做一期视频」废话——必须给到可开拍的角度
- ❌ 不自动发布、不自动写平台；入库/淘汰全部人工确认
- ❌ 用户昵称不入库（存簇 ID 追溯），评论数据只用于频次统计

## 调用示例

**输入**（`examples/input.json`，节选）：

```json
{
  "account": "@小鹿的好物日记",
  "period": "2026-09-23 ~ 2026-09-29",
  "existing_topics": ["新手化妆顺序教程", "平价粉底液合集"],
  "faq_clusters": [
    {"代表问题": "在哪买", "提问频次": 6},
    {"代表问题": "新手怎么画", "提问频次": 2}
  ]
}
```

**输出**（节选，见 examples/output.md）：

| 选题ID | 来源问题簇 | 频次 | 优先级 | 选题建议 | 查重结果 | 状态 |
|---|---|---|---|---|---|---|
| T001 | 在哪买 | 6 | 高 | 「WHERE 买指南」：全渠道购买攻略 + 防坑清单 | 新增 | 待人工确认 |
| T003 | 新手怎么画 | 2 | 低 | 「新手 0 基础」分步教程 | 与既有「新手化妆顺序教程」重复 | 建议淘汰 |

## 所属工作流

- `faq-to-topic-flow`（高频问题转选题的末端环节）

## 合规声明

- 本技能输出为 **AI 辅助整理结果**，入库/淘汰必须经人工确认
- 选题涉及品类宣称（功效/价格）在拍摄脚本阶段另行过合规审查
- 输出标注「AI 生成内容」；选题库仅内部使用
