## 四、边界与已知限制

| 限制 | 说明 |
|---|---|
| 语义查重盲区 | 用词完全不同的近似选题（「平替合集」vs「学生党好物」）需模型语义复核 |
| 频次时效 | 提问热度随内容波动，条目频次标注统计周期，跨期需重跑聚类 |
| 闭环依赖人工 | 「已拍」状态与播放数据回填靠人工执行，不回填则 ROI 统计失效 |
| 只读连接器 | 平台评论数据为人工导出只读，不自动抓取、不自动写任何平台 |
