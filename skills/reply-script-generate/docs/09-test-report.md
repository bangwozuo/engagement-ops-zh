## 二、内容深度自检（D1-D5）

| 维度 | 证据 |
|---|---|
| D1 领域术语 | 先答后引/反向互动/接情绪给事实给出口/不认罪式道歉/同簇复用/流量分发/一致性检查 |
| D2 量化约束 | 草稿 15-60 字；句长 ≤20 字；口头禅 ≤1 条/回复；称呼命中率 ≥80%；SLA 黑粉 30 分钟/吐槽 2 小时/提问 4 小时 |
| D3 方法/算法 | 三类评论三套结构化策略（各 3-4 步）+ 批量排序规则 + 自检流程 |
| D4 领域边界 | 不与黑粉对线（截图反噬）、万能模板群发出戏、「以后注意」式空话无效、意图不明不猜 |
| D5 输出可交付 | 草稿表（# / 评论ID / 类别 / 草稿 / 字数 / 策略说明）+ 自检表 + 需人工决定清单 |

## 四、边界与已知限制

| 限制 | 说明 |
|---|---|
| 纯生成无脚本 | 本技能为 T2 文本生成，一致性打分依赖 persona-voice-library 的脚本 |
| 反讽语境 | 意图不明的评论（如「就这？」）不自动生成，进需人工决定清单 |
| FAQ 时效 | 引用 FAQ 答案要点时依赖其口径为最新（月度校对） |
| 平台差异 | 字数与称呼习惯以输入 voice 的 platform 为准，跨平台需调整档案 |

## 五、结论

**通过。** prompt 深度达标（T2 ≥1200 字），示例草稿经脚本实测全部过一致性检查，
三条合规硬红线（承诺/导流/绝对化）零命中。
