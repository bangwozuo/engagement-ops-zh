# 回复话术生成

按评论类别（提问/赞美/吐槽/黑粉）+ 语气库约束，写出**能直接粘贴发布、过一致性
检查、不出戏**的回复草稿。草稿全部 `[待人工确认]`，发布由人工执行。

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_media_03_sk03` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 评论运营官 |
| 能力族 | 文本生成型 · 评论区维护 |
| 复杂度 | `S` |
| 阶段 | `P0` |
| 复用度 | 高（reply-script-advice-flow 核心环节、superfan 流的感谢话术） |
| 资产形态 | 纯提示词（无运行时依赖、无 API Key） |

## 能力描述

1. **三类策略**：
   - 提问 →「答案 + 出处/钩子」（15-40 字，先答后引，口径只指平台内路径）
   - 赞美 →「具体感谢 + 反向互动」（≤30 字，复述对方夸的点或抛二轮问题）
   - 负面 →「接情绪 + 给事实 + 给出口」（30-60 字，不认罪式道歉 + 可验证改进点）
2. **黑粉专用**：澄清一次不追辩，第二条攻击性评论建议隐藏/举报（人工执行）
3. **语气库硬约束**：称呼 ≥1 个、口头禅 ≤1 个、句长 ≤20 字、禁用词零命中，自检
   称呼/口头禅命中率 ≥80%
4. **批量排序**：黑粉 → 吐槽 → 提问 → 赞美（对齐处理 SLA），同簇问题只写一条标准答案

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `comments` | array | ✅ | 待回复评论（id/user/text/类别；类别来自 comment-sentiment-analyze） |
| `voice` | object | ✅ | 语气库档案（称呼/口头禅/句长上限/禁用词，来自 persona-voice-library） |
| `faq` | array | ⬜ | FAQ 库 Top10（命中时直接引用标准答案要点，不重复造答案） |

## 输出规格

- `drafts`：回复草稿表（# / 评论ID / 类别 / 草稿 / 字数 / 策略说明），按 SLA 排序，逐条 `[待人工确认]`
- `self_check`：称呼命中率 / 口头禅每条数 / 禁用词与合规词命中数
- `need_human`：建议置顶、建议隐藏/举报的评论清单

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 提供评论列表 + 语气库档案（+ FAQ 库可选）
4. 得到按 SLA 排序的草稿表与自检结果，人工确认后发布

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude / ChatGPT** | 新建 Project/GPT → Instructions → 粘贴 `prompt.txt` |

生成后的草稿建议再过一遍 `persona-voice-library` 的脚本检查（`voice_check.py`），
达标（≥80 分）再发。

## 边界（不做的事）

- ❌ 不承诺效果、不引导站外交易、不用绝对化用语（三条硬红线）
- ❌ 不与黑粉对线、不反讽、不建议删评（违规内容由人工举报）
- ❌ 不编造事实（订单号/检测报告/合作信息）；缺信息给承诺式回复
- ❌ 不做"万能模板群发"——逐条对应具体评论
- ❌ 不执行发布——草稿全部待人工确认

## 调用示例

**输入**（`examples/input.json`，节选）：

```json
{
  "comments": [
    {"id": "C001", "user": "奶盖不加糖", "category": "提问",
     "text": "姐这个粉底液色号是多少呀？黄二白能用吗"},
    {"id": "C005", "user": "打工人小王", "category": "吐槽",
     "text": "广告太多了，划水的部分能不能剪掉"}
  ],
  "voice": {"称呼": ["宝子", "姐妹"], "口头禅": ["亲测", "说真的"],
            "句长上限": 20, "禁用词": ["绝绝子", "亲～"]}
}
```

**输出**（节选，见 examples/output.md）：

| # | 评论ID | 类别 | 回复草稿 | 字数 |
|---|---|---|---|---|
| 1 | C005 | 吐槽 | 姐妹说得对！这期广告是硬了点，以后植入提前说，节奏也在改，说真的感谢反馈。 | 38 |
| 2 | C001 | 提问 | 宝子，黄二白选 12 号不假白，亲测～对比在置顶视频 2 分 30 秒。 | 30 |

自检：称呼命中率 100%，口头禅各 1 个，禁用词 0，均 `[待人工确认]`。
